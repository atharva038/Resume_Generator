# SmartNShine Premium Editorial Portfolio Template

> **Design Direction:** Minimalism × Editorial Typography × Subtle Luxury × Modern Product Design  
> **Aesthetic:** Quiet Luxury + Serious Professional + Creative Intelligence

---

## 🚀 Live Access in Your Web Application

- **Standalone Live Template Route:** `http://localhost:5174/smartnshine-portfolio` (or `/smartnshine`)
- **Theme Selection in Portfolio Builder:** Choose **"SmartNShine Editorial"** in the Portfolio Dashboard / Editor theme picker.

## ✨ Features & Sections Included

1. **Floating Minimalist Navigation:**
   - Monogram logo (`S·N / SmartNShine`)
   - Smooth navigation links with animated underline micro-interactions
   - Independent **Warm Ivory (Light)** / **Deep Charcoal (Dark)** theme switcher
   - "Let's talk ↗" action trigger
   - Mobile slide-down menu

2. **Typography-Led Hero Section:**
   - Small eyebrow: `PORTFOLIO / 2026` + Location + Live Availability Pulse indicator
   - Giant editorial headline: *"Building thoughtful digital experiences."*
   - Personal introduction & Current Role focus tag
   - Animated scroll indicator & subtle watermark number `01`

3. **Continuous Marquee Ticker:**
   - Seamless animated skill & discipline marquee with champagne gold star bullets

4. **Featured Work (Selected Projects):**
   - Editorial project composition (Numbered `01`, `02`, `03`)
   - Category tag, Title, Year, One-line summary, Tech stack badges
   - Interactive hover image scale and arrow movement

5. **Asymmetrical Editorial About Section:**
   - Large statement: *"I like building things that are simple to use and difficult to ignore."*
   - Detailed biography
   - 4-cell structured matrix: Education, Focus, Location, Interests
   - Download CV / Resume button

6. **Numbers & Stats Section:**
   - Editorial large numbers (`12+ Projects`, `04 Years Experience`, `08+ Core Tech`, `03 Shipped Products`)

7. **Refined Vertical Experience Timeline:**
   - Period / Duration, Company, Role, Narrative summary, and bulleted contributions with tiny gold markers

8. **Categorized Skills System:**
   - Categorized under `DEVELOPMENT`, `DESIGN & UI`, `TOOLS & INFRASTRUCTURE`
   - Clean typography with numbered indices (No generic percentage bars)

9. **Recognition & Testimonials:**
   - Minimalist editorial blockquotes with author and organization metadata

10. **Memorable Contact Section:**
    - Statement: *"Have an idea? Let's build it."*
    - Direct email touchpoint with diagonal arrow
    - Online presence grid (LinkedIn, GitHub, Twitter / X, Dribbble)
    - Availability status badge

11. **Minimal Footer:**
    - Monogram branding, copyright credit, and back-to-top button.

## 📝 Customization

All default data is located in `client/src/data/smartNShinePortfolioData.js`. You can edit your name, role, projects, experience, skills, and links in one file or generate it dynamically from the resume builder!
